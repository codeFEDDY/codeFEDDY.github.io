What this tool does

Deterministic means boring in the best possible way.

Changes

Only alpha bytes inside the selected rectangle.

Preserves

Every RGBA channel outside the rectangle and every RGB channel inside it.

Requires

A modern browser. No server, login, API key, or AI model.

Privacy

File processing happens in browser memory on your device.

Limits

8-bit single-frame PNG overlays up to 30 million pixels. References may be PNG, WebP, or JPEG.
